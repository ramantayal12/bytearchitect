You are given the meetings scheduled for a day as `intervals`, where `intervals[i] = [start, end]` means meeting `i` runs from time `start` up to, but not including, time `end`.

A room can host one meeting at a time. A meeting that ends at time `t` frees its room for a meeting that starts at `t`.

Return the minimum number of rooms needed to hold all the meetings.

<Examples />

**Constraints:**

- `1 <= intervals.length <= 10^5`
- `0 <= start < end <= 10^7`

**Follow-up:** also assign each meeting to a room, numbered from `0`, so that the number of rooms is minimal. Which data structure tells you which room frees up first?
