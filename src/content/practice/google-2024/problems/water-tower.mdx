You are given an `m x n` grid `heights` describing a landscape, and the positions of two cities, `city1 = [r1, c1]` and `city2 = [r2, c2]`.

You want to build **one** water tower on a cell of the grid so that both cities can be supplied with water. Pipes run between horizontally or vertically adjacent cells (never diagonally), and water can only flow **downhill or on the level**: from a cell to a neighbour whose height is less than or equal to the current cell's height. A tower may stand on a city's own cell.

Return the position `[row, col]` of the **highest** cell whose water can reach both cities. If several valid cells have the same greatest height, return the one with the smallest row, then the smallest column. If no cell can supply both cities, return `[-1, -1]`.

<Examples />

**Constraints:**

- `1 <= m, n <= 200`
- `0 <= heights[i][j] <= 10^6`
- `city1` and `city2` are valid cells (they may be the same cell).
