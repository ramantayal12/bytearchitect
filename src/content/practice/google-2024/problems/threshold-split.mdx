You are given an array `nums` of positive integers and an integer `threshold`.

Divide `nums` into one or more non-empty **contiguous** parts, so that every element belongs to exactly one part. Your score is the number of parts whose sum is **at least** `threshold`.

Return the maximum score you can achieve.

<Examples />

**Constraints:**

- `1 <= nums.length <= 10^5`
- `1 <= nums[i] <= 10^4`
- `1 <= threshold <= 10^9`

**Follow-up:** how does your answer change if `nums` may contain zeros or negative numbers?
