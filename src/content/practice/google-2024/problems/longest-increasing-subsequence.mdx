Given an integer array `nums`, return the length of its longest **strictly increasing subsequence**.

A subsequence keeps some of the elements, in their original order, and may skip any number of them.

The report describes an onsite round built on this problem, with two follow-ups on top. Solve the core first, and fast: `nums` can have `10^5` elements.

<Examples />

**Constraints:**

- `1 <= nums.length <= 10^5`
- `-10^9 <= nums[i] <= 10^9`

**Follow-ups:**

1. Return one longest increasing subsequence, not just its length.
2. Count how many longest increasing subsequences there are.
