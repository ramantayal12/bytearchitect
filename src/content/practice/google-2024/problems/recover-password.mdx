A password is made of **distinct** characters (letters and digits). You intercepted some fragments of it: each fragment lists some of the password's characters **in the same relative order** as in the password, but not necessarily next to each other. Fragments can have different lengths.

Every character of the password appears in at least one fragment, and the fragments always come from a real password.

Return the password. If more than one password is consistent with all the fragments, return the **lexicographically smallest** one, comparing characters by their character codes (digits < uppercase < lowercase).

<Examples />

**Constraints:**

- `1 <= fragments.length <= 1000`
- `1 <= fragments[i].length <= 62`
- `fragments[i]` consists of English letters and digits, with no repeated character.
- The fragments are consistent with at least one password.

**Follow-up:** instead of the smallest password, report whether the password is uniquely determined.
