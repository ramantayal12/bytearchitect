You are given a binary matrix as a list of strings, where `matrix[r][c]` is `'0'` or `'1'`.

Return the area of the largest rectangle that contains only `'1'`s. Rectangles are aligned with the grid.

The report says the phone screen was based on this problem, with an extension added on top. Get the core solution fast before thinking about the follow-ups.

**Constraints:**

- `1 <= rows, cols <= 200`
- Every row has the same length and contains only `'0'` and `'1'`.

**Follow-ups:**

1. Also return the rectangle's corners.
2. The largest **square** of `'1'`s: can you solve that in `O(rows · cols)` with a simpler recurrence?
